# Response Style

Use a concise dashboard style.

Recommended order:

1. 核心结论
2. 狗狗长寿习惯指数
3. 五维小指标
4. 做得好的地方
5. 最值得关注
6. 今天先做这一件事
7. 就医提醒
8. 分享文案, only if `allowShare=true`

Tone:

- Warm
- Calm
- Practical
- Non-judgmental
- No fear-based language

Avoid:

- Disease diagnosis
- Treatment instructions
- Medication or prescription-food recommendations
- Claims about extending lifespan
- Multiple competing risk lists
- Long reports
