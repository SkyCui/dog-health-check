# WorkBuddy 测试版发布记录

版本 0.1.0。2026-10-31 开始，跨午夜后仍以当次实际操作状态记录。

## 已完成

- GitHub main 与 Vercel 已发布 `/api/mcp` 和公开安装包。
- 官方 MCP SDK 客户端：本地开发、生产构建、公网各17项测试通过。
- 原有测评 API 20场景、知识库完整性、29项顾问路由等回归通过。
- 生产依赖 npm audit 未发现告警；初次完整依赖审计有16项中风险开发依赖告警，未执行破坏性批量修复。
- Skill frontmatter 与根问卷/schema 一致性通过替代检查；官方 Python 校验脚本因缺 PyYAML 未运行成功。
- WorkBuddy 5.9.3：用户登录并明确授权信任后，自定义连接器启用。
- 该客户端对话返回能力信息、带 AAHA/WSAVA 来源的零食建议、呼吸困难 safety 分流，以及合成两天观察的 recordedDays=2/actionCompletedDays=1。未使用真实宠物资料。
- 首次测试粘贴时夹带了客户端默认示例文字，出现无关资料汇总计划后已取消；改用清空输入框后重新发送限定工具测试。

## 尚未完成的验收

- 配套 Skill 的宿主安全检测、安装及自然语言触发。
- WorkBuddy 公开市场提交与审核。自定义安装成功不等于市场上架。
- 云数据库、账户授权、持久化档案与跨会话记忆：按用户决定等待资源配置，不在本版假装提供。

工具无模型调用；WorkBuddy 模型及其用户额度仍会消耗，不能说整个使用过程没有 Token 成本。
