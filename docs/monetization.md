# MVP 付费与权益设计

## 已确定方案

| 权益 | 免费范围 | 买断价格 | 包含内容 |
| --- | --- | --- | --- |
| 幸福自测 | 7 次 | ¥1.99 | 永久不限次自测 |
| Plus 身心喂养 | 首个咨询会话，最多 5 轮 | ¥9.99 | 永久不限次知识库咨询、个性化计划、建议出处 |

Plus 只提供个性化知识建议，不包含真人兽医或营养师咨询，也不提供诊断、处方粮替代、药物/补充剂剂量或声称完整均衡的通用自制食谱。

## 当前上线范围

- Web 已实现首个 5 轮咨询会话的本地权益记录和 Plus 升级入口。
- 咨询接口和知识库可直接运行，不依赖模型 API Key。
- 未配置 `NEXT_PUBLIC_PLUS_CHECKOUT_URL` 时，升级按钮显示“支付接入准备中”。
- 7 次自测与 ¥1.99 买断已进入统一计划配置，尚未在没有账号和服务端权益前强制拦截。

## 正式收费前必须补齐

1. 用户身份：手机号、微信、小红书平台身份或其他可恢复账号。
2. 服务端权益：免费次数、Plus 状态、购买时间与退款状态不能只放在浏览器。
3. 订单：服务端创建订单，不信任客户端传入价格和商品。
4. 支付回调：校验签名、金额、商户订单号，处理重复通知和幂等。
5. 权益恢复：跨设备登录后恢复购买，提供订单查询和退款后的回收逻辑。
6. 合规文案：服务内容、非真人咨询、退款规则、隐私与健康信息处理说明。

本地存储可被清除或修改，因此当前免费轮次只能验证产品体验，不能作为正式收费安全边界。
