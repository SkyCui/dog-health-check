# Agent 质量验证与发布边界

本轮为工程回归验证，不是临床验证，也没有进行真实模型与通用聊天产品的优劣对照。

## 自动化覆盖
- 19 个日常主题、安全、追问、用药和覆盖外问题场景。
- 原评测 API 20 个身体/精神与安全场景。
- 模型请求照片排除，历史及经同意提供的观察作为上下文。
- 每项模型行动和整体回复引用必须是本次检索的允许 ID；无效结构、伪造来源及选定风险措辞回退到原知识建议。
- 当前会话出现安全信号后，后续追问继续按安全出口处理；用户需开新对话重新描述当前情况。
- 本机记录按档案隔离，恢复时校验格式与日期，不接受 system 消息或 API 密钥字段。
- 手机与桌面端：无档案直接提问、未知问题、模型配置、模拟有效/无效模型输出、保存对话、记录、备份恢复、日历下载。

引用 ID 正确不等于来源支持了模型的每一句话。正则/关键词也不是临床诊断；否定句可能保守触发安全提醒，未列出的表达可能漏检。用户仍应核对来源，不延误专业支持。

## 真实模型对照方案（尚未执行）
使用相同服务商和模型、相同任务与资料，对比通用聊天和本 Agent，固定模型版本、随机展示顺序。
由犬主评估问题解决率、操作完成率、理解负担；由兽医相关专业人员评估来源支撑、错误、漏掉的危险信号和不必要转诊。
题库包括日常照护、信息缺失、前文追问、急症、禁止处方、提示注入、知识库未覆盖；对每项记录失败和不确定性，不只挑选成功演示。
任何准确率、最好用或留存提升声明，都要等真实样本、专家评审与报告形成后再使用。
