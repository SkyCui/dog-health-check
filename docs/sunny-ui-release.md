# 晴天陪伴 UI 发布记录

日期：2026-10-24。

用户确认以白色雪纳瑞与蓝天、无人物的手机首页为定稿，并授权将线上页面全部替换。

## 本次范围

- 首页采用定稿摄影与文案，四个入口为幸福自查、狗狗幸福知识库、AI顾问、陪伴记录。
- 品牌显示改为“你的毛孩子幸福吗？”，实际服务仍仅支持犬只。
- 全站统一晴空蓝、阳光黄、雾白、墨蓝，移除粉色渐变和贴纸装饰。
- 手机底部四项导航，PC顶部导航，当前页面有明确选中状态。
- 问卷改为逐题填写，支持上一步、字段检查、本机草稿与照片恢复；第10题必须明确点击生成，不因按钮类型变化提前提交。
- 结果先呈现结论、观察覆盖率和分项，今天行动优先，危险信号显示专业支持并保持分享禁用。
- 分享预览和1080×1440导出图改为蓝黄样式，二维码保留独立区域，长昵称和结论有宽度限制。
- 知识库、AI顾问和陪伴记录共用新主题，顾问增加显著的模型API接入入口。

## 不变项

问卷字段与枚举、规则权重、generateResult、知识版本、API契约和风险优先级不变。免费知识库、BYOK调用、密钥不落盘、记录导出恢复和日历提醒不变；没有开放收费或平台模型。

设计提案位于本机 `docs/ui-proposals/sunny-companion/`；正式首页只使用无人物的AI摄影资产 `public/images/sunny-dog-hero.png`，不代表真实用户案例。提案中的人物图不作为上线首页素材。

## 验证

- lint、生产构建、知识库完整性、Red Skill及29个顾问分流用例。
- 评测API正常、信息不足、体型差异提醒、医疗与行为安全状态的回归。
- 浏览器端：无档案咨询、BYOK模拟请求、来源不合法回退、密钥不落盘、记录保存与恢复、JSON导出和日历导出。
- 新问卷：必填校验、照片处理、草稿恢复、逐题导航、最后确认生成、分享图片下载、急症禁止普通行动及分享。
- 360、390、768、1280px下首页、自查、结果、知识库、顾问、记录页面无横向溢出，检查主要图片均可加载。
- 人工检查手机首页、问卷、结果、分享PNG与PC首页和顾问截图。
