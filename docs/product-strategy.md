# 犬只日常照护 Agent：产品与增长策略

## 现状与可证明范围
上线前版本仅有 8 个喂养知识主题，单主题关键词选择、无关问题默认落到喂养、无长期观察记录，模型回复未经引用结构校验。因此不能声称优于通用大模型。
本次升级到 12 个日常主题：喂养、体况、零食、换粮、自制、生食、嗅闻丰富化、生命阶段、放松、选择式互动、观察史、口腔照护。
“垂类最好用”是目标，不是已经验证的结论。产品当前面向犬只，不自动扩展到猫或其他宠物，也不称为兽医或临床权威专家。

## 用户任务与路径
1. 第一次访问：直接获得免费知识库建议；无须先填十题或配置密钥。
2. 需要更贴合个体：建立幸福自查档案，保留身体与精神双维度及已有安全出口。
3. 深入追问：免费接入自己的模型。按当前问题与近期前文检索最多三个知识主题，提供有来源的观察建议。
4. 执行：每天只跟进一件事，记录进食、精神、便便和可选体重/备注，不制造诊断分数。
5. 回访：下次回到首页出现当前档案的继续入口，保存对话可选，日历提醒由用户主动导入。
6. 增长：原有幸福卡含 dogcare.cc 二维码，知识条目可以直接带问题进入顾问；不把急症提示锁在模型配置后。

## 成本与信任
默认知识库建议、风险分流、记录和检索均在浏览器执行；模型由用户自己的服务商计费，不使用平台密钥。
API 密钥只在当前页面内存。对话保存需用户勾选；观察记录主动点击保存。记录与照片无后台上传，最近 7 天记录传给用户模型需要独立同意。
浏览器数据不等于云同步，换设备或清理数据可能丢失；提供观察 JSON 备份与恢复。当前按昵称与品种区分本机档案，同名同品种需使用不同昵称；重命名不会自动迁移历史。
托管和流量仍可能有费用，不承诺无限访问量下全部运营成本为零。平台收费模型仍为待更新。

## 验证指标
北极星指标假设：每周至少完成一次有意义的照护行为并在另一日回访的家长数。不能以聊天条数替代真实照护。
- 激活：首次访问后完成自查、保存观察或标记建议有帮助中的任意一项。
- 任务成功：用户能完成“找到依据 → 明确一步行动 → 记录结果”的流程。
- 留存：第 7/28 天有实质行为的回访，而不是仅打开页面。
- 增长：分享入口到达率、到达后激活率。
- 质量守门：安全场景分流、无依据问题拒答、虚构来源回退、用户未解决反馈。

当前不部署跨用户埋点或上传健康对话，因此不能给出全站增长、留存或满意度数字。反馈只在本机记录；记忆开启后才持久化。后续须另行实现自愿、最小化事件收集，再开展漏斗分析。没有实际样本之前不宣称增长提升。

## 后续优先级
先进行犬主可用性访谈与兽医行为/营养专家内容审核，再与同一底模的普通对话进行盲测。其次才考虑更多主题、可选云同步和新物种支持。推送、账号、付费与收集用户数据不作为本轮上线前提。
